
# 4 Servo Motors Control with Arduino UNO 🤖

## 📌 Project Description
This project demonstrates how to control four servo motors using an Arduino UNO.
The servo motors are programmed to move between different angles using the Arduino Servo library.

## 🛠️ Components
- Arduino UNO R3
- 4 × Servo Motors

## 🔌 Pin Connections

| Servo | Arduino Pin |
|------|-------------|
| Servo 1 | D3 |
| Servo 2 | D5 |
| Servo 3 | D6 |
| Servo 4 | D9 |

## 💻 Software
- Arduino IDE
- Tinkercad Circuits
- Arduino Servo Library

## ⚙️ How It Works
The Arduino controls four servo motors simultaneously.
Each servo moves to 90°, then 40°, then 140°, creating a repeated movement pattern.

## 🎯 Result
All four servo motors successfully move together according to the programmed angles.
